# LFK Customs Shop Manager v2.0

**Handcrafted Wood Works · Houston, TX**  
Built by Damian J Schumacher · Powered by dbappsystems.com · Built with Claude AI

---

## Stack

- **Frontend:** React 18 + Vite
- **Hosting:** Cloudflare Pages
- **AI:** Claude API (AI Helper tab)
- **Fonts:** Google Fonts (Playfair Display, Source Sans 3, Courier Prime)

---

## Features (10 Tabs)

| Tab | Feature |
|-----|---------|
| 🏠 Home | Dashboard — revenue, projects, web orders at a glance |
| 🛍️ LFK Store | Full public-facing storefront with cart + checkout |
| 📬 Store Orders | Manage all incoming web store orders |
| 🪵 Wood Inv. | Wood species inventory with board-foot tracking |
| 🔧 Tools | Shop tool & supply inventory |
| 📋 Projects | Custom project/order pipeline with status tracker |
| 🧾 Invoices | Invoice creation, editing, and print-ready view |
| 📦 Shipping | Shipment form + dim weight calculator |
| 💳 Payment | Payment link generator (Stripe, PayPal, Venmo, etc.) |
| 🤖 AI Helper | Claude AI assistant for listings, pricing, content |

---

## Local Development

```bash
npm install
npm run dev
```

## Cloudflare Pages Deployment

1. Connect `dbappsystems/LFK-customs` repo in Cloudflare Pages dashboard
2. **Build command:** `npm run build`
3. **Output directory:** `dist`
4. **Node version:** 18+
5. Deploy!
